# DP365

A one-year habit tracker: strength, cycling, mindfulness, water and food, with a daily brief, a drag-and-drop day timeline, and weekly and monthly recaps.

- `index.html` is the app, served by GitHub Pages.
- `src/app.html` is the source; run `python3 src/build.py` to rebuild `index.html` after editing it.

All logged data stays in the browser on the device that uses it.
